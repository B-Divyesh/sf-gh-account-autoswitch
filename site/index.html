01 / How account rules work

Choose an account before gh runs

The command uses your rules and accounts already signed in to the GitHub CLI.

  1. 01

    Read the repository

    Check its origin remote and current folder.

  2. 02

    Find the first complete match

    Each field in a rule must match. Rules are checked from top to bottom.

  3. 03
    ›_

    Run the command with that account

    The selected token goes only to the GitHub command you started.

03 / Ways to match a repository

Write small rules for each account

~/.config/gh-accounts.toml
# The first complete match wins.
version = 1

[[rules]]
name = "Acme work"
account = "dev@acme.example"
host = "github.com"
owner = "^acme-corp$"

[[rules]]
name = "Personal"
account = "octocat"
directory = "~/src/personal/**"
host
Match one GitHub or GitHub Enterprise Server host.
owner
Match an organization or user name pattern.
remote
Match the complete host, owner, and repository path.
directory
Match a local folder pattern.

What the command does not change

Keep other GitHub commands untouched

01

Keeps the active account

It never runs gh auth switch.

02

Does not save tokens

A selected token is not printed, logged, or added to the rules file.

03

Stops without a match

If no rule matches, it exits with code 3 and does not run gh.
