Policy / 2026-08-27

Privacy

gh-account-autoswitch is local-first software. The CLI and this documentation site do not collect, transmit, sell, or analyze personal data.

CLI data

The CLI reads your local working directory, Git remote URL, local rule file, and account metadata reported by your installed GitHub CLI. It requests a token from gh only after a rule matches. The token is passed to one child process and is never written, printed, or sent anywhere by this project.

Website data

This static site includes no analytics, tracking pixels, advertising, remote fonts, or third-party runtime scripts. Your hosting provider may retain ordinary request logs under its own operational policy.

Local storage

The site uses a service worker cache so documentation remains available offline. It contains only public site files and can be cleared through your browser settings.

Contact

Report privacy or security concerns through the project’s GitHub issue tracker. Never include credentials or tokens in a report.
