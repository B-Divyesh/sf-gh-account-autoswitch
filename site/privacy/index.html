Policy / 2026-08-28

Privacy

The command runs on your computer. This website does not include analytics, advertising, remote fonts, or third-party scripts.

Command data

The command reads your current folder, Git remote, rules file, and account names reported by the GitHub CLI.

After a rule matches, it asks the GitHub CLI for that account’s token. The token is given only to the command you started.

The project does not print, log, or save that token. It does not run gh auth switch.

Demo data

The browser demo uses fixed public examples and does not use browser storage. Reset restores those examples.

The CLI demo creates a temporary folder, reads only bundled sample rules, and removes the folder before it exits.

Website requests

The site loads its code, images, icon, and offline files from this website. It sends no account or repository data.

The hosting provider may retain ordinary request logs under its own operational policy.

Offline files

A service worker caches public site files after the first visit. Clear the cache through your browser settings.

Contact

Report a concern in the GitHub issue tracker ↗. Do not include credentials or tokens.
